## 🪐 Tổng Quan Dự Án

Dự án **Elyriax** hướng tới việc thiết lập một trung tâm tiện ích phân phối đa nền tảng, tập trung cốt lõi vào sự tinh gọn cấu trúc và phản hồi luồng dữ liệu thời gian thực. Hệ thống được tối ưu hóa để vận hành như một Single Page Application độc lập, bảo mật và mở rộng không giới hạn.

- **Thẩm mỹ:** Giao diện Dark-mode đồng bộ sâu, chuyển đổi trạng thái hiệu ứng mượt mà.
- **Kiến trúc:** Phân tách module độc lập, sẵn sàng cho việc tích hợp các cổng kết nối API hệ thống.
- **Tương thích:** Đáp ứng hoàn hảo trên mọi thiết bị di động và môi trường trình duyệt tiêu chuẩn.
